# ZERO / ZERO PiNG

**خدای اپ‌های VPN** — اکوسیستم یکپارچه فروش، مدیریت و اتصال VPN.

> این مخزن فعلاً **فقط معرفی پروژه** است. سورس اپ و Worker هنوز منتشر نشده.

## خلاصه

| لایه | نقش |
|------|-----|
| **بات تلگرام** | فروشگاه کامل + نمایندگی + شارژ کیف پول |
| **مینی‌اپ (Telegram WebApp)** | UI شیشه‌ای RTL  |
| **اپ اندروید ZEROPiNG** | کلاینت VPN واقعی (sing-box / libbox) |
| **پنل‌ها** | تحویل خودکار سرویس از پنل‌های V2Ray / WireGuard |

## ۱) بات + مینی‌اپ 

- فروشگاه محصول / دسته / سبد / سفارش
- کیف پول و شارژ با رسید
- پنل‌های چندگانه (PasarGuard / Rebecca / auto)
- رفرال (درصد / ثابت / سقف)
- نمایندگی (Agency)
- داشبورد ادمین، مانیتور KV/D1، آپلود تصویر محصول
- پشتیبانی چندبات روی یک سورس (آینده)

**وضعیت زنده (مرجع عملیاتی):** Worker `zero-vpn-v31` · مینی‌اپ روی همان دامنه Worker · بات `@Gamegozar_app`

APIهای کلیدی (سطح بالا):

- `GET /api/shop` — محصولات و دسته‌ها
- `GET /api/userinfo` — نقش و موجودی
- `POST /api/topup` — شارژ
- `POST /api/service` — جزئیات سرویس (حجم/روز/آنلاین)
- مسیرهای ادمین برای محصولات، پنل‌ها، سفارش‌ها

## ۲) اپ اندروید — ZEROPiNG

کلاینت بومی Kotlin + Jetpack Compose:

| قابلیت | وضعیت هدف |
|--------|-----------|
| تب Home / Servers / Subscription | ✅ UI |
| ایمپورت اشتراک (URL / پیست) | ✅ |
| پارس چندفرمتی (VLESS, VMess, Trojan, SS, Hysteria2, TUIC, WG + base64 + JSON) | ✅ |
| تست تأخیر و انتخاب خودکار بهترین نود | ✅ |
| موتور چندگانه با اولویت **sing-box (libbox)** | ✅ اسکلت + وابستگی |
| VpnService + نوتیفیکیشن foreground | ✅ |
| ادغام با Worker (دریافت کانفیگ / وضعیت سرویس) | 🔜 در حال اتصال |

**حداقل سیستم:** Android 8 (API 26) · JDK 17 · Compose

## ۴) معماری داده (سمت سرور)

- **KV** برای تنظیمات، تصاویر سبک، وضعیت پویا
- **D1** برای متا و سفارش‌ها
- تصاویر محصول فقط به‌صورت path (`/api/img/...`) — بدون base64 داخل cfg
- بدون قرار دادن secret ادمین داخل اپ

---

## ۵) حریم و امنیت

- توکن بات و کلیدهای ادمین فقط در Secrets ورکر
- اپ فقط با توکن محدود / شناسه کاربر تلگرام صحبت می‌کند
- مجوز VPN سیستم اندروید برای تونل اجباری است
